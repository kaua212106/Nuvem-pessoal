Como começar

Seus arquivos ficam em um repositório seu no GitHub. Faça a configuração uma única vez.

  1. No GitHub, crie um repositório e um Personal Access Token com permissão de leitura e escrita em Contents.
  2. Informe usuário, repositório e token em Configurações e teste a conexão.
  3. Envie seus arquivos e gerencie tudo em Meus Arquivos.

O token fica salvo apenas neste navegador (localStorage) e é enviado somente para api.github.com. Use um token com acesso restrito a este repositório.

Com PIN, o token fica criptografado neste navegador e o PIN é pedido ao abrir o app. Vazio = salva sem PIN.

Se ativado, o token será incluído no arquivo JSON em texto legível. Use somente no seu celular e não compartilhe nem envie esse arquivo para a nuvem.

O backup inclui usuário, repositório e favoritos. O token só é incluído quando você marcar a opção acima. Para maior segurança, deixe-a desmarcada.
